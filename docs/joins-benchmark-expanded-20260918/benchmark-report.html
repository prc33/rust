Interpretation and protocol notes

  • Protocol matrix records the exact validation invariant and any intentional protocol mismatch for each row.
  • Samples are independent timed runs after warmups; bootstrap intervals quantify run-to-run variation, not compiler-version uncertainty.
  • Handwritten rows are the existing std::sync primitives, except async-request, which is the Tokio current-thread baseline.
  • Join rows use the compiler extension and the same participant counts where the protocol permits. Shared multi-rule endpoints use the temporary expanded-artifact capture repair documented by the build script; the rustc checkout is unchanged by this benchmark run.
  • Optimize mode can select the compiler’s direct isolated-unary lowering. Multi-input and competing-rule cases retain matcher/executor overhead until their CFA proofs are strong enough.
  • Compare ratios only within an operation. A join and baseline row may normalize different useful work when a protocol has multiple replies; operation counts in the detail table make that explicit.
